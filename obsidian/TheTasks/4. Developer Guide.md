# Developer Guide

A quick reference guide for setting up, building, and developing components in TheAndb.

## ⚡ Environment Quickstart

1. **Hydrate Submodules & Workspace**:
   ```bash
   pnpm install
   ```
2. **Build Core & Packages**:
   ```bash
   pnpm --filter @the-andb/core build
   ```
3. **Launch Desktop Development Server**:
   ```bash
   npm run dev:desktop
   ```
4. **Spin up Local Test DBs**:
   ```bash
   docker-compose -f docker/docker-compose.yml up -d
   ```
   *This starts DEV (port 3307) and PROD (port 3310).*

## 🛠️ Code Intelligence (GitNexus)

This project utilizes GitNexus for code comprehension and impact analysis.
- **Rules before Editing**:
  - Run impact analysis using: `gitnexus_impact({target: "symbolName", direction: "upstream"})`.
  - Always review the risk level before modifying core functions.
  - Run `gitnexus_detect_changes()` prior to commits to review modified scope.

## 🎨 Vue & Desktop Styling Best Practices

- **Strict Type Checks**: All helper mappings must use explicit typescript typing (e.g. avoid `any` where possible, or annotate variables strictly).
- **Universal Components**: Reusable components such as `UniversalDataGrid` must be used when displaying grids in both `TableDataInspector` and `QueryConsole`.
