# Roadmaps & Feature Strategy

This note details the roadmap, current plans, and feature layout for TheAndb desktop application.

## 🗺️ Feature Expansion (Beta Launch & Beyond)

### Pillar 1: Beta Soft-Gate & Registration (Completed)
- **Soft-Gate Guard**: On the first launch, the desktop application prompts the user with a sleek registration screen (Name, Email, Use Case).
- **Offline Resilience**: If registration API calls fail, the gate automatically bypasses to ensure offline developers are not blocked.
- **Unified UX**: Implements `UniversalDataGrid` in both Table Inspector and Query Console to provide a consistent grid behavior, keyboard shortcuts, and column resizers.

### Pillar 2: Dynamic Query Limits & Settings
- Integrated custom limits (e.g., 50, 100, 500, 1000 rows) and setting dropdowns for layout customizations directly in the Query Console toolbar.

### Pillar 3: AI DBA Integration
- Allowing secure schema sharing and audits through AI endpoints.
- Generating automated database performance recommendations.

---

## 🚀 Key Database Management Capabilities

### Schema Auditing
- Quick detection of column modifications, missing indexes, and charset drift between databases.

### Grid Operations
- Context menu options: Copy Cells, Set Null, UPPERCASE, lowercase, and Capitalize.
- Staged row insertions at the bottom of the data inspector.
