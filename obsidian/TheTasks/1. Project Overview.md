# Project Overview: TheAndb 🛸

**TheAndb** is a professional database schema reliability engine designed for high-stakes production, featuring AST-powered safety, semantic diffing, and multi-environment orchestration.

## 🌟 Key Differentiators

- **Live-State Diffing**: Allows developers to diff live `dev` environments directly against `prod` environments without needing a complex migration history.
- **Safety-First Engine**: Every migration is analyzed using AST parsers to flag potentially destructive operations (e.g., dropping columns, narrowing column types) and warn engineers before deployment.
- **Rich Aesthetics**: Provides human-readable diffs, visual drift reports, and modern styling matching state-of-the-art tools.
- **AI-Ready Integration**: Bundled with a Model Context Protocol (MCP) server to allow AI agents like Claude/ChatGPT to perform automated schema audits safely.

## ⚖️ Dual-Track License Model

TheAndb codebase is split into two tracks:
1. **Open Core (AGPL-3.0)**:
   - Includes `@the-andb/core` (the engine), `@the-andb/cli`, `@the-andb/mcp` (MCP Server), and landing page/docs (`andb-www`).
2. **Desktop App (Proprietary)**:
   - Includes the premium Electron/Vue GUI (`andb-desktop`) which is closed source but free for individual use.
