## Why sponsor

Shipping a schema-diffing engine that has to be _correct_ across MySQL and Postgres, an Electron desktop app, a CLI, and an MCP server is more than a side-project's worth of work. Sponsorship goes directly toward:

- **Development time** — the hours spent fixing real bugs (like schema drift edge cases) instead of only new features
- **Cross-platform testing** — MySQL 5.7/8.0, Postgres, macOS/Windows/Linux
- **CI/CD & infrastructure** — the pipelines and test fixtures that catch regressions before you hit them
- **Documentation** — keeping the docs honest and current, not an afterthought
- **Release cadence** — shipping fixes and features on a predictable schedule instead of whenever there's spare time
