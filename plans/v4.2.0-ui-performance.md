# SPRINT PLAN: v4.2.0 - Desktop UX/UI Performance

## 🎯 Goal
Eliminate UI lag, jank, and freezing when loading or scrolling through massive databases. Improve perceived performance via lazy-loading and smart DOM rendering.

## 🛡️ Safety & Architecture Check
- **Execution mode**: N/A (UI only).
- **Architectural rules**: Must use direct imports from `@the-andb/core`. Must not spawn core as subprocess.

## 📋 Tasks

### 1. Virtual Scrolling
- [ ] Cài đặt thư viện virtual scrolling (VD: `vue-virtual-scroller`).
- [ ] Thay thế vòng lặp `v-for` truyền thống trong component hiển thị Table/Row.
- [ ] Đảm bảo tính toán chiều cao dòng chính xác (Dynamic height).

### 2. Lazy-Load Monaco Editor
- [ ] Refactor component Editor SQL.
- [ ] Thay vì bundle toàn bộ Monaco, sử dụng Dynamic Import `() => import('monaco-editor')` chỉ khi người dùng bấm vào tab Query.

### 3. Skeleton UI & State Feedback
- [ ] Xóa bỏ toàn bộ loading spinners cục bộ.
- [ ] Bổ sung Skeleton Layouts cho Sidebar và Data Grid.
- [ ] Cập nhật Progress Bar (Observer Pattern) khi `compareSchema` đang chạy.

### 4. CSS Render Optimization
- [ ] Bổ sung thuộc tính `contain: strict` vào các layout cố định (Sidebar, Toolbar).
- [ ] Tránh dùng CSS expressions hoặc layout trashing do JS tính toán kích thước liên tục.
