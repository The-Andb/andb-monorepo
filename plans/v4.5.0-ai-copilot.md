# SPRINT PLAN: v4.5.0 - Local AI Copilot

## 🎯 Goal
Integrate AI features to enhance Developer Experience (DX) while strictly adhering to the "Local-first" privacy philosophy.

## 🛡️ Safety & Architecture Check
- **Execution mode**: Dry-run by default. AI generated code must NEVER execute automatically.
- **Architectural rules**: No business logic leak. LLM integrations must be isolated in a dedicated service.

## 📋 Tasks

### 1. Ollama Integration (Local LLM)
- [ ] Thêm thiết lập cấu hình Ollama host/port.
- [ ] Viết prompt chuyên biệt sinh SQL từ text mô tả của người dùng.

### 2. AI SQL Explanation
- [ ] Bổ sung nút "Giải thích" cạnh mỗi câu lệnh DDL khó hiểu.
- [ ] Gửi SQL string cho LLM yêu cầu giải thích sang tiếng Việt.

### 3. Contextual Vector RAG
- [ ] Khi gửi yêu cầu sinh SQL, không nhồi toàn bộ schema (gây tràn token).
- [ ] Tạo module Vector search nhỏ trên local (như `sqlite-vss` hoặc faiss-node) để nhặt ra 3-5 bảng liên quan nhất nhét vào prompt.

### 4. Auto-Commit Message for Schema Changes
- [ ] Tự động sinh nội dung giải thích "Tại sao đổi cấu trúc này" trước khi user ấn nút Apply Migration.

## 🧪 Verification
- Thử nghiệm tắt mạng Internet và sinh SQL từ Ollama.
- Đảm bảo AI prompt không vô tình chứa lệnh `DROP TABLE`.
