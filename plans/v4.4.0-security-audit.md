# SPRINT PLAN: v4.4.0 - Local-First Security & Audit

## 🎯 Goal
Elevate the application to Enterprise-grade security standards. Protect sensitive credentials and trace all destructive actions.

## 🛡️ Safety & Architecture Check
- **Execution mode**: N/A (Security Layer).
- **Architectural rules**: Never store, log, or hardcode secrets in plain text.

## 📋 Tasks

### 1. Credentials Encryption
- [ ] Tích hợp cơ chế mã hóa AES-256 cho chuỗi Connection (Password, SSH Keys).
- [ ] Lưu key mã hóa vào OS Keychain (macOS Keychain, Windows Credential Manager) qua API của Electron.

### 2. Local Audit Logging
- [ ] Hook vào tất cả các lệnh `EXECUTE` (DDL, DML).
- [ ] Ghi log có cấu trúc (JSON) ra thư mục cục bộ `~/.theandb/audit.log`.
- [ ] Ghi nhận thời gian, loại lệnh, và kết quả.

### 3. Security Pre-flight Checks
- [ ] Khi kết nối DB mới, cảnh báo nếu Password quá yếu (ví dụ: `123456`, `root`).
- [ ] Cảnh báo user nếu kết nối SSL/TLS không hợp lệ (Self-signed) trên production env.

### 4. Secure Wipe Data
- [ ] Thêm tính năng "Xóa toàn bộ dữ liệu & cấu hình".
- [ ] Ghi đè file SQLite chứa cấu hình 3 lần trước khi xóa (Zero-fill) để chống khôi phục.

## 🧪 Verification
- Thử đọc file SQLite chứa cấu hình (bằng trình DB khác) để đảm bảo không nhìn thấy password dạng plain text.
