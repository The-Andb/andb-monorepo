# SPRINT PLAN: v4.3.0 - Database Engine Enhancements

## 🎯 Goal
Enhance database read/write safety and speed across supported drivers (MySQL, PostgreSQL, SQLite). Ensure we don't crash user databases with heavy queries.

## 🛡️ Safety & Architecture Check
- **Execution mode**: Dry-run by default unless explicitly executing DML/DDL.
- **Locking strategy**: MUST use advisory locks (`GET_LOCK`) on MySQL when syncing.
- **Architectural rules**: Keep all driver logic behind `ConnectionFactory` strategy pattern.

## 📋 Tasks

### 1. Automatic Query Limiter
- [ ] Bắt (intercept) các câu lệnh `SELECT` thuần.
- [ ] Bổ sung `LIMIT 1000` tự động nếu phát hiện không có mệnh đề LIMIT.
- [ ] Hiển thị thông báo trên UI: "Results limited to 1000 rows. Click to fetch more."

### 2. SQLite WAL Mode
- [ ] Trong `SqliteDriver.connect()`, bổ sung cờ `PRAGMA journal_mode=WAL`.
- [ ] Kiểm tra tính tương thích khi ứng dụng Desktop đọc file `.sqlite` song song với app khác.

### 3. Bulk Data Transfer Optimization
- [ ] **Postgres**: Thay thế cơ chế INSERT mảng bằng lệnh `COPY FROM STDIN`.
- [ ] **MySQL**: Hỗ trợ export data dưới dạng CSV và nạp bằng `LOAD DATA LOCAL INFILE`.

### 4. Connection Keep-Alive
- [ ] Implement cơ chế Ping/Heartbeat qua SSH Tunnel để chống timeout.
- [ ] Thiết lập Connection Pool thay vì mở connection mới cho mỗi câu Query.
