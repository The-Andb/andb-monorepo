# TheAndb Desktop GUI Guide

## 🏙️ Application Overview
TheAndb Desktop is a premium, glassmorphic database workspace designed for structural safety and semantic analysis. It provides a visual layer over the `andb-core` engine.

## 🧭 Navigation & Layout
- **Sidebar**: Access your Projects, Global Search, and Settings.
- **Main View**: The primary workspace for viewing database schemas and comparing environments.
- **AI Sidebar (The "Brain")**: A persistent panel on the right where the AI-DBA Assistant lives.

## 🔌 Connection Management
- **Connection Tokens**: TheAndb uses "Tokens" to store connection credentials securely.
- **Templates**: Standardize connection settings across your team.
- **Support**: Supports SQLite, MySQL, and PostgreSQL (via introspection).

## 🕵️ Schema Explorer
- **Live Inspection**: Browse tables, views, and procedures directly from your database.
- **Semantic Mapping**: View how your database is structured, including foreign keys and dependencies.
- **Filters**: Quickly filter objects by name, type, or size (Small/Medium/Large).

## 🤖 AI-DBA Assistant
The AI Assistant is integrated into every part of the GUI:
- **Chat**: Ask general questions about your database architecture.
- **Review**: Select any DDL object (Table/View) and click **Review** to get an automated safety audit.
- **Explain**: Highlight complex SQL to have the assistant explain the logic in plain language.
