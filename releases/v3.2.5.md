# 🚀 TheAndb Desktop v3.2.5 Release Notes

## 🎉 What's New

### 1. 🛡️ Project Protection & Safe Deletion
Data safety is our priority. We've introduced a robust project protection mechanism:
- **Protect/Unprotect Projects**: You can now lock projects by clicking the newly added 🛡️ Shield icon. A protected project cannot be deleted.
- **Secure Inline Confirmation**: The clunky browser-native `confirm()` dialogs are gone! Project deletion now requires an explicit typed confirmation of the project name in a dedicated modal, preventing accidental clicks.
- **Safer Bulk Delete**: Bulk deletion automatically ignores any protected projects in your selection.

### 2. 🗂️ Excluded Items Visibility in Compare View
- **New "Excluded" Filter**: In the Compare (Diff & Sync) view, you can now toggle the visibility of schema items that were ignored or excluded by the engine (e.g. Migration Exclusions). Excluded items are marked with a 🚫 Ban icon, keeping your diffs transparent.

### 3. 🗺️ Unified Workspace Navigation (Sidebar Migration)
- **Goodbye Global Dropdowns**: We've fully removed the global Connection and Sync Pair dropdowns from the top Header.
- **Contextual Sidebar Integrations**: Workspace selection is now entirely driven by the Sidebar. 
    - The `appStore.selectedConnectionId` now automatically syncs when you click database nodes.
    - Sync Pair selection is directly integrated into the Compare View’s explorer header for a cleaner, unified UX.

### 4. 🎨 UX Polish & Bug Fixes
- **Environment Pills**: Replaced the generic dropdown for selecting Environments with quick-select "pill" tags in the Connection Settings, making configuration much faster.
- Fixed a `DUPLICATE_CONNECTION` console error that occurred during environment toggling by refining reactivity in `connectionTemplates.ts`.

### 5. 🔄 Workspace Upgrade Note
- **Safe Continuation**: When upgrading to v3.2.5, your existing workspaces, projects, connections, and sync pairs are **safely continued and automatically migrated** to the new robust format. 
- **No Overwrites**: The update **will not overwrite** any of your existing database configurations. Your current state is fully preserved.
