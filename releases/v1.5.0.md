# 🚀 TheAndb v1.5.0: The Automation Update

## 🎉 What's New

### 1. 🔄 Git Sync & CI/CD Fundamentals
Bringing database schemas into the modern DevOps era:
- **Git Sync Integration**: Automatically snapshot your database schema and commit it directly to your Git repository within the Desktop app.
- **Headless CLI Alpha**: Introduced the foundational `andb-cli` to enable running schema comparisons and migrations strictly from your terminal environments.

### 2. ⚡ Performance Upgrades
- **Parallel AST Parsing**: Rewrote the parser multi-threading pipeline in Rust-WASM to parse 500+ table schemas in under a second.
- **Cross-Platform Support**: Official stable distributions now available for Windows (`.exe`) and Linux (`.AppImage`).
