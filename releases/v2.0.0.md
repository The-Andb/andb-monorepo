# 🚀 TheAndb v2.0.0: Schema Intelligence

## 🎉 What's New

### 1. 🧠 Contextual Trees & Instant Compare
A massive overhaul to how developers view differences between environments.
- **Instant Code Compare**: A split-pane code diff editor allows you to selectively push individual `ALTER` statements instead of forcing a full bulk migration.
- **Contextual Syntax Highlighting**: Fully embedded PrismJS for SQL dialects, making reading complex stored procedures and triggers highly legible.
- **Go To Definition**: Cmd/Ctrl+Click any table ref or foreign key inside your DDL viewer to instantly jump to its definition.

### 2. 🛡️ Deployment Tools
- **Pre-flight Checks**: Before any migration executes, the engine runs a dry-run integrity check against live database dependencies.
- **1-Click Migration**: Completely bypass manual SQL execution. One click syncs your source logic safely into the destination.
- **Detailed History & Logs**: Execution logs are now permanently archived locally for audit-trail compliance.
