# 🚀 TheAndb v1.0.0: The Genesis Release

## 🎉 What's New

### 1. ⚙️ Core Syncing Engine
Welcome to TheAndb! We set out to solve the fundamental problem of database drift. V1 introduces our bulletproof AST-based schema comparison engine.
- **Semantic Diffing**: We don't just diff text. TheAndb parses your DDL into an Abstract Syntax Tree (AST) to genuinely understand the structural differences between tables, views, and routines.
- **Zero-Data-Loss Guarantees**: Our migration compiler strictly analyzes operations to ensure destructive actions (`DROP TABLE`, `DROP COLUMN`) require explicit safety overrides.

### 2. 🖥️ Desktop App Beta
- **Native MacOS Support**: Blazing fast, lightweight desktop client built specifically for database engineers.
- **Connections Manager**: Securely store and manage your test, staging, and production database credentials locally.
