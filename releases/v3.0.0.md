# 🚀 TheAndb v3.0.0: The AI Ecosystem

## 🎉 What's New

### 1. 🤖 Model Context Protocol (MCP) Server Launch
TheAndb is now an AI-Native Database assistant.
- **Cursor & Windsurf Integration**: Provide your AI agents with direct, real-time access to your database schema contexts via the official `andb-mcp` package.
- **Analysis Workflows**: Let AI generate migrations, detect environmental drift, and suggest indexing optimizations automatically using our exposed MCP tools (`compare_schema`, `get_object_ddl`).

### 2. 🏗️ Monorepo Transition
- We have completely re-architected TheAndb into an NX Monorepo. This allows the CLI, Core Engine, Desktop App, and Web platforms to dynamically share AST logic and typings, ensuring zero discrepancies across ecosystems.
- **Headless Orchestration**: The core engine was functionally decoupled so enterprise users can run multi-env routing natively in CI runners.
