# Commercial Usage Guidelines

The Andb is a **source-available** project, not open source. This document clarifies the distinction between allowed evaluation usage and restricted commercial usage.

## ✅ Allowed Usage (Community / Evaluation)

You are free to use The Andb without a paid license for the following purposes:

- **Local Testing:** Installing and running the application on your personal machine to evaluate its features.
- **Education:** using the source code for learning, academic research, or teaching.
- **Development of Plugins (Private):** developing private integrations or plugins for your own personal use.
- **Non-Commercial Hobby Projects:** Managing personal databases that do not generate revenue.

## ❌ Prohibited Usage (Commercial)

You **maintain NO rights** to use The Andb for the following without a commercial license:

- **Production Deployment:** Using The Andb to manage production databases for a business or commercial entity.
- **Internal Company Tools:** Deploying The Andb as an internal tool for a team within a company.
- **Cloud Hosting / SaaS:** Hosting The Andb on a server and providing access to others as a service.
- **Paid Products:** Embedding or bundling The Andb (in whole or in part) into a product that you sell.
- **Consulting Services:** Using The Andb as a primary tool to deliver paid consulting services to clients.
